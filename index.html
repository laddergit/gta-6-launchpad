The Project · 01
What is it

GTA 6 Launchpad is a token launchpad built on Base. Its token ticker is $GTA6L — supply 1,000,000,000, not yet created, so the contract address is still marked Soon. Anyone can create and launch a token — no code, no presale games, no insider allocations. Every launch starts on a bonding curve, open to everyone from block one.

The landing page is live first. The launchpad app ships separately — this is the front door.
